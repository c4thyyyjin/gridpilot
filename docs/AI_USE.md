# AI use statement

I used Claude (Anthropic) and Codex (OpenAI) throughout this project for
planning, coding, testing and documentation. This project contains
AI-generated code and I want to be upfront about that.

## How I used each tool

| Stage | What I did | How AI helped |
|---|---|---|
| Project setup | I chose the problem (data-center power-compute co-scheduling), picked the track (Huawei/Hithium), and decided what to model | Claude helped me outline the project plan, draft initial assumptions in ASSUMPTIONS.md, and write the first versions of the data generator, evaluator and baseline |
| Scheduling core | I ran the schedulers, compared outputs, and reported bugs when PuLP and SciPy disagreed | Codex wrote the PuLP/CBC scheduler; Claude wrote the SciPy/HiGHS version. I integrated them and we cross-checked results across seeds and carbon weights |
| Robustness work | I identified which limitations to tackle (5–7: online/delayed/ramp controllers) and requested each fix | Claude and Codex built the causal MPC variants, observation-delay models, ramp limits, checkpoint overhead, and the service/safety guards. I tested each version locally |
| Laxity scheduling | I asked for improvements to recover the 19/26 oracle-feasible deadline failures | Claude designed and implemented the least-laxity-first dispatcher, the ramp-aware deliverable-energy helpers, and the 40-test regression suite. I ran the studies on seeds 200–219 and 220–239 |
| Evaluator fixes | I flagged the green-share >100% bug, NaN/negative-power acceptance, and chart labelling issues | Claude added input validation, corrected the green-share accounting, labelled ineligible bars, clarified the battery chart, and locked DT_H to hourly resolution |
| Economics & reporting | I supplied the project folders at each step and asked for experiment regeneration and limitation reviews | Codex wrote the feasibility-aware reporting, paired confidence intervals, economic sensitivity analysis, grid-cap sweep, and battery-investment tables |
| Documentation | I reviewed and edited the generated docs, corrected wording I disagreed with, and requested specific changes | Claude and Codex drafted the review documents, README, and this disclosure. I edited them for accuracy and tone |

## Project ownership and implementation attribution

I coordinated the project, chose what to build, decided which fixes to pursue,
reviewed outputs, and requested local execution and independent verification. I edited
AI-generated text where it was wrong or unclear.

I did not write every function myself. The scheduling algorithms, LP
formulations, test suites and most of the analysis code were generated by
Claude and Codex. I did not author those components from scratch.

I have not independently verified every external source cited in ASSUMPTIONS.md.
The parameter values are referenced there, but I relied on the AI tools to find
and format them.
